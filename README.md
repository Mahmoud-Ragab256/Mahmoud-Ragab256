## 🚧 What I'm Building

### Multi-Activity ERP · In Development

I'm developing an ERP for small and medium businesses, starting with service and maintenance companies in Egypt. I'm working across identity and access, inventory, sales, and purchasing.

One workflow I'm building connects sales orders to inventory reservations. When a customer receives part of an order, the system records what shipped and keeps the remaining stock reserved against the same order.

| Workstream | Current focus |
| :--- | :--- |
| **Identity & access** | Sign-in, sessions, and permissions across company operations |
| **Inventory** | Stock movements, reservations, and partial fulfillment |
| **Sales** | Orders, deliveries, and invoices |
| **Purchasing** | Purchase orders, receiving, and invoice matching |

## 🧩 How I Work

1. **Map the workflow** — Identify who uses the feature, what they can access, and how the data changes.
2. **Define the API and data model** — Specify what endpoints accept, validate, and return.
3. **Connect the interface** — Handle real data, loading states, validation errors, and empty states.
4. **Verify the behavior** — Test successful and rejected requests, document reproducible issues, and share changes through Git and GitHub.
