## 🚀 Featured Projects

### 🏨 Hotel Management System
> A full-featured RESTful API for hotel operations — built as my DEPI Graduation Project.

- 🔐 JWT Auth with role-based access control (Guest / Staff / Admin)
- 📦 Full CRUD for rooms, bookings, invoices, services & notifications
- 📧 Email OTP for password reset via Nodemailer
- 🛡️ Security: Helmet, bcrypt, rate limiting, Joi validation

**Stack:** `TypeScript` `Node.js` `Express` `MongoDB` `JWT` `Nodemailer`
